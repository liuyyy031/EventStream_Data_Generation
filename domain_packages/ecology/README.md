# Ecology：陆地生境斑块的资源—消费者—捕食者事件流

这是 Ecology 的首个可运行子范围，不把全部生态系统、各物种或真实野外动力学缩成同一模型。目标是得到**拓扑、状态、时间与文本证据相互一致**的合成事件流；参数是可见的合成先验，未用生态数据拟合，也不声称统计真实性。

## 节点及静态关系

| 实体 | 在这一子范围中的含义 | 可用于判断的关系 |
|---|---|---|
| `ecoregion` | 共享一次区域扰动的合成生态区域 | 每个斑块属于一个区域 |
| `habitat_patch` | 有面积、质量属性的陆地生境单元 | 与资源、种群和廊道相连 |
| `resource_pool` | 可供本地草食种群利用的合成生物量 | 每个斑块有主资源池，允许额外背景资源池 |
| `population` | 具有 `guild` 的本地草食、捕食或潜在入侵种群 | 消耗资源、捕食、竞争关系必须与 guild 匹配且落在同一斑块 |
| `corridor` | 两斑块之间有距离和通透率的潜在扩散通道 | 两端点构成不规则连通树；不保证入侵确实传播 |

默认每张图 1000 个实体、约 165 个斑块，使用稀疏类型关系；不会创建千节点平方矩阵。`population` 不是传感器或道路的换名：它有基线丰度和明确的摄食角色。图的连通性只说明潜在接触，实际事件父子关系必须满足对应机制、同区域或同斑块绑定、动态状态条件以及候选风险时钟触发。一次 episode 只在一片区域或一处入侵起点启动，未进入事件流的其它斑块仍保留为上下文，不把它们伪造成“无影响”的观测结论。

## 三条事件机制

1. `regional_drought`：区域干旱开始；成员斑块经过各自资源响应延迟，资源因子下降。只有实际每个有效消费者可用资源低于阈值，才启动草食种群下降的风险时钟；只有草食种群已经下降到基线的 80% 以下，才启动捕食者下降时钟。干旱结束后，只对已受影响的斑块安排资源恢复；种群恢复仍需单独时钟。
2. `resource_pulse`：区域资源脉冲使各斑块资源增加。只有资源/消费者超过阈值，才有草食种群增长风险；只有草食种群超过基线的 120%，才有捕食者增长风险。脉冲结束后资源恢复基线，但并不伪造瞬时种群回落。
3. `invasive_colonization`：一处斑块收到繁殖体；“建立成功”和“建立失败”是同一到达事件后的**竞争风险**，只能发生其一。建立成功时先形成低丰度种群，随后才可能经过竞争响应延迟而增长；增长确实使本地草食种群的有效人均资源跌破阈值时，才出现资源下降与后续种群响应。同时，仅可沿真实廊道向相邻斑块产生随机扩散候选；连通不等于必然传播。

资源及种群状态按事件顺序更新；条件消失时未发生的候选会取消，到观察窗仍未触发的保留右删失。父事件标签是**本生成模型内**经机制规则支持的关系，并非野外实验测得的因果效应。

## 数值和时间合同

本包使用简化的合成资源指标，而非生态承载力微分方程：

\[
A_p(t)=\frac{B_p f_p(t)}{\max(1,H_p(t)+1.2 I_p(t))}.
\]

`B` 为主资源池基线生物量，`f` 为资源扰动因子，`H` 为草食丰度，`I` 为入侵丰度；`A` 的标注单位是合成 kg/有效消费者。不同斑块有不同的 `B`、干旱/脉冲响应因子与入侵增长潜力，因此同一区域扰动不会自动造成所有斑块的种群变化。草食下降条件 `A<2.5`，增长条件 `A>5.0`；捕食者响应需检查本地猎物是否跨过基线的 80% / 120%。这些数值、30%/40% 的种群变化和入侵竞争系数均为**设计先验**，不是文献标定或普适生态阈值。它们使状态转移可复算、可测试，后续换子领域时必须重新定义。

事件等待时间使用已有通用时间机制而非固定时间桶。区域开始使用指数到达时钟；干旱、资源脉冲、资源变化和恢复采用条件对数正态延迟；种群反应、入侵建立/失败和廊道扩散使用按状态和属性重算的分段指数风险时钟。后者保留已累积风险，不在状态变化时重新抽签。内部统一记录秒；日级设定的速率先除以 86400，文本以天显示。默认观察窗 180 天，未发生事件可右删失。日志入库时间晚于合成离线真值的发生时间；并未模拟野外监测设备何时获知每个变化。

这里借鉴的是[干旱野外实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC3479754/)对食物网级联是否普遍成立的实证约束，以及[资源条件下入侵竞争实验](https://doi.org/10.1007/s10530-023-03039-x)提示的情境依赖性；这些研究**没有提供本包的数值参数**。现阶段缺少物种个体、繁殖季节、死亡/迁出、食物替代、天气空间场、疾病、随机监测漏报及真实数据拟合。通过结构校验和 LLM Judge 只说明内部一致性及语义审核通过，不证明生态真实性。

输出复用公共 `events.jsonl`、`event_relations.jsonl`、`candidates.jsonl`、文本对齐、QA 与训练视图。上传和测试见 [Ecology 测试协议](../../docs/ECOLOGY_TEST_PROTOCOL.md)。
