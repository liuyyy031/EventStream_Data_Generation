# Energy：配电馈线事件流

这个包把 Energy 的首个可运行范围限定为**单条径向配电馈线**。目标是生成节点含义、事件前驱、受影响范围和时间顺序相互一致的数据，供后续事件流理解任务使用；不是完整电网、潮流、保护整定或统计真实性模拟。能源领域不等同于配电，发电市场、输电、储能、油气等仍未覆盖。

## 节点与拓扑

| 类型 | 含义 | 必须满足的关系 |
|---|---|---|
| bus | 电气连接点；0 号为馈线根母线 | 非根母线恰有一条入线，线路组成无环树 |
| line | 上游母线到下游母线的一段馈线 | 一条 `line_from_bus` 和一条 `line_to_bus` |
| breaker | 保护一条线路的开关 | 恰有一条 `breaker_protects_line` |
| load | 接在某母线上的负荷组 | 恰有一条 `load_attached_to_bus` |
| generator | 根母线上的主电源、备用电源 | 各有一条 `generator_connected_to_bus` |

默认 1000 个节点约含 250 个 bus、249 个 line、249 个 breaker、250 个以上 load 和 2 个 generator。具体数量由节点预算确定。它不是道路网格或节点平方的幅值矩阵，而是稀疏、带类型的馈线关系。静态连线只定义物理可达性，绝不自动成为事件父子关系。

## 三种事件机制

1. `line_fault`：线路故障 → 该线保护断路器打开 → 沿该线**下游全部**负荷停电 → 线路修复完成 → 断路器闭合 → 相同负荷恢复 → 汇总结束。只从有 2–12 个下游负荷的线路抽样，是为了让单个 episode 可审查，不代表真实线路最多只服务 12 个负荷。
2. `demand_surge`：某负荷需求升高，所在线路的合成下游需求超过该线额定值；经观测延迟产生高负载事件。高负载激活跳闸风险时钟，需求恢复另有独立时钟。若需求先恢复，跳闸候选取消，无停电；若先跳闸，下游负荷停电，并且**只有需求恢复后**才允许闭合、复电。记录候选取消/右删失，而不是强制一种结局。
3. `generation_shortfall`：主电源出力下降 → 低备用余量观测 → 备用机组调度候选；主电源恢复也有独立时钟。先实际恢复可用容量的一方成为 `reserve.restored` 的父事件，另一候选若已失效就取消；恢复标记只出现一次。较晚的主电源恢复仍可作为单独事件保留。

`causal`、`observation`、`transition`、`workflow` 在关系中分开标记。多父节点的 `surge_reclose` 必须同时指向实际的断路器打开事件和需求恢复事件；`workflow.settled` 的父节点是所有实际已恢复的下游负荷，不是图上邻居。

## 时间机制与依据

| 过程 | 实现 | 合成参数 |
|---|---|---|
| 初始故障/需求变化/出力下降等待 | 指数到达 | rate 0.12/s；每个 episode 只选择一个初始场景，非全网平稳故障率 |
| 故障保护动作 | 对数正态延迟 | 中位数基准 0.08s，sigma 0.35，下界 0.005s |
| 维修完成 | 对数正态延迟 | 中位数基准 45s，sigma 0.45，下界 5s |
| 负载/备用观测 | 对数正态延迟 | 中位数基准 0.25s，sigma 0.4，下界 0.01s |
| 需求恢复 | 对数正态延迟 | 中位数基准 3s，sigma 0.5，下界 0.2s |
| 过载跳闸 | 分段指数风险率 | `h(t)=0.25 exp(0.8 × overload_ratio(t))`，仅在过载仍成立时有效 |
| 主电源恢复、备用调度 | 各自对数正态延迟 | 中位数基准 3s / 2s，均为 sigma 0.7；两个时钟允许任一先到 |
| 安全闭合等待 | 确定性延迟 | 前置条件满足后 1s；仅是合成策略值 |
| 停电/复电记录、汇总 | 即时确定性 | 父事件满足后同一时刻发生 |
| 入库延迟 | 对数正态延迟 | 本地 `observed_at=occurrence`，`recorded_at` 稍后 |

模型族复用公共时间库；上表数值全部是本项目的透明合成先验，**不是**文献给出的电网参数，也未用真实电网记录校准。保护装置通过断开故障段使下游停电、修复后再恢复供电的机制方向，参考美国能源部的[配电系统基线报告](https://www.energy.gov/sites/prod/files/2017/01/f34/Electricity%20Distribution%20System%20Baseline%20Report.pdf)及[径向线路/保护技术报告](https://www.energy.gov/sites/prod/files/2016/12/f34/SCE-ISGD-TPR-1_Final_Dec_2014.pdf)。这些资料支持事件顺序的合理性，不能证明本合成参数或输出分布符合真实电网。

## 数据合同与限制

输出仍是公共的 `entities`、`context_relations`、`events`、`event_relations`、`candidates`、`risk_sets`、文本/QA/训练视图。领域 validator 从导出的拓扑和事件重新检查节点类型、径向下游范围、断路器与线路绑定、安全复电、过载阈值及单次容量恢复。LLM Judge 可审核文本及机制逻辑并驳回有问题的 episode；语义矫正仅能改写有证据支持的文本，不能改变结构、时间或答案。

负荷用聚合 MW，线路额定值是基于下游基线负荷构造的合成阈值；没有电压、相位、无功、潮流计算、网络重构、重合闸序列、联络开关、孤岛、负荷切除、分布式发电或保护协调。备用容量情景只表达**总容量不足与恢复**，不把它伪装为对每条线路的潮流求解。当前单次 episode 只有一个主要扰动，不代表能源系统事件类型的完整覆盖。

上传、测试和服务器 LLM 命令见 [Energy 测试协议](../../docs/ENERGY_TEST_PROTOCOL.md)。
