# Climate：理想化低频温度异常与监测

当前实现的是**外部辐射强迫—有热惯性的温度异常—阈值与持续性—采样报告**子域，不是日常天气生成器或完整气候系统模拟。
它沿用公共调度、稀疏类型图、时间单位、候选取消/右删失、语义审核/矫正、QA、训练导出与共享前缀续生成，没有使用交通传播假设。

## 1. 节点和连接对应什么

| 类型 | 含义 | 关键属性 |
| --- | --- | --- |
| `climate_unit` | 虚构的面积平均一箱气候响应单元，不代表已验证的真实地理区域 | 有效热容量 J/(m²·K)、阻尼 W/(m²·K)、暖/冷异常阈值 K |
| `forcing_driver` | 作用于某个单元的外部有效辐射强迫输入源 | 强迫含义；实际脉冲的强度、正负和时长记录在事件中 |
| `anomaly_observer` | 对模型低频温度异常取样的理想观测实体，不是未经处理的真实气象站 | 点快照采样策略 |
| `climate_service` | 接收报告、发布/撤回基于样本的监测通报 | 最新可用样本策略 |

三种功能边为 `driver_forces_unit`、`observer_samples_unit` 和 `observer_reports_to_service`。
每个单元绑定两个驱动源与一个观测实体；服务实体可以接收多个观测实体的报告。
不为了全图连通添加单元之间的随机边，也不声称模拟了单元间大气/海洋热输送。
不同单元应理解为独立的理想化响应案例，不是把同一真实地球切成互不影响的区域。

1000 个背景节点默认是 245 单元、490 驱动源、245 观测实体、20 服务实体，共 980 条功能边。
每个 episode 选择一个单元及其绑定实体生成局部片段，不保证 1000 个节点都出现在事件中。
节点连边本身不构成事件父关系。

## 2. 四类情景与输出事件

| 情景 | 外源候选 |
| --- | --- |
| `warming_pulse` | 一个正强迫脉冲 |
| `cooling_pulse` | 一个负强迫脉冲 |
| `combined_warming` | 两个可独立到达的正强迫脉冲 |
| `opposing_forcings` | 一个正、一个负强迫脉冲，可以重叠或错开 |

情景决定候选个数；指数时钟只决定这些候选的到达时间，不是持续产生无限事件的完整泊松过程。
强迫是预先规定的有效辐射异常 W/m²，不能直接当作 CO₂ 浓度或排放量。

13 种事件包含：强迫开始/结束、实际强迫叠加计算、暖/冷阈值进入/退出及持续确认、样本、报告、通报发布/撤回。
14 个机制包括首个观测日程和后续观测日程两个实现机制。
强迫弱、持续短或相互抵消时可以没有阈值事件，更不能为了凑齐链路强制确认。

## 3. 时间与状态为什么这样生成

### 3.1 已有模型与本项目的选择

采用已有的一箱能量平衡模型的确定性受限形式，模型方程及一箱模型的局限可见
[Williamson et al., 2024，§2、§3](https://esd.copernicus.org/articles/15/829/2024/index.html)：

```text
C dT/dt = F − λT
F = sum(F_i)
τ = C/λ
T_eq = F/λ
T(t+u) = T_eq + [T(t) − T_eq] exp(−u/τ)
```

这里 T 是相对虚构固定基准的温度异常 K，t/u 为秒，F 为 W/m²，C 为 J/(m²·K)，λ>0 为阻尼 W/(m²·K)。
每个恒定强迫段直接取解析解；一箱只有一个响应时间尺度，未实现深海慢响应、空间耦合或天气噪声。
这不是对原论文全部方法的复现，也没有移用其统计拟合结论。

恒定脉冲近似、四类情景、节点绑定、参数范围、阈值、采样和通报策略是本项目的合成设计。
默认 λ∈[0.8,1.6]、τ∈[3,8] Julian year、阈值 ±0.7 K 等不是普适气候常数，也未拟合真实区域。
温度异常参考的是合成稳态零点；[WMO 的气候标准正常值](https://public.wmo.int/media/news/its-warmer-average-what-average)使用长期数据基准，本实现没有计算这样的实测正常值。
默认观察窗为 30 年并不使合成零点自动成为 WMO 正常值，也不能把阈值事件当作真实气候归因。

### 3.2 阈值越过的 Δt

给定当前 T、T_eq 与目标 T_*：

```text
r = (T_* − T_eq)/(T − T_eq)
Δt = −τ ln(r)           # 仅当 0 < r < 1
```

目标不可达或只能渐近到达时，不生成有限越界时间。到达阈值后还检查实际变化方向，区分进入与退出。
每次强迫开始/结束会保留当前温度和累计能量，取消旧段的未来越界候选，再推导新段的剩余时间。
**强迫结束不等于温度瞬间归零**，异常会依热惯性逐步衰减。
改变采样频率不会改变物理时间轴；采样日程不是模拟分箱。

### 3.3 持续确认

暖异常从向上越过 +0.7 K 开始，向下越过同一阈值结束；冷异常方向相反。
默认连续保持一年才确认。候选绑定实际越界开始事件；期间若退出就取消，不把不连续片段累计成一次持续异常。
强迫改变但异常没有退出时，不重新计时。
一年仅是合成确认策略，不是 WMO 对气候变化、热浪或归因的通用判定。

### 3.4 能量账本

每条事件保留并回放检查：

```text
C [T(t) − T(0)] = cumulative_forcing_energy − cumulative_feedback_energy
T(0) = 0
```

两项能量均按 J/m² 记录，可以为负；这是相对基准的能量异常预算，不是绝对热含量。
正负强迫叠加后为零时，已有温度异常仍然衰减，不能把强迫相抵误写成温度立即相抵。

### 3.5 不同的时间机制

| 内容 | 当前时间机制 |
| --- | --- |
| 有限个强迫根候选的到达 | 指数到达合成先验，默认平均等待 2 年 |
| 脉冲结束 | 开始时抽取脉冲时长后形成确定性日程，默认 5–14 年 |
| 暖/冷阈值进入/退出 | 当前状态与能量平衡解析解 |
| 连续异常确认 | 实际进入事件后的配置时长，并受退出取消约束 |
| 采样 | 固定观测日程，默认每一个 Julian year |
| 报告、通报审阅、日志摄入 | 对数正态延迟先验，尚无经验协变量拟合 |

事件类型与时间共同受到当前状态和机制约束；没有先独立抽任意类型、再给其配一个与内容无关的 Δt。

## 4. 多父关系与文本表达

`forcing_superposition.evaluated` 的父事件是同一单元上**当前仍生效的实际强迫开始事件**。
它表示算术叠加的 `derivation`，不是“两个驱动节点相连，所以共同导致气候变化”。
单元已有温度与历史能量也影响后续演化；当前段起点父事件并不抹去这些历史。

通报撤回的父事件是实际已发布通报与更新的样本报告。
其他关系区分 `transition`、`derivation`、`scheduled`、`communication` 与 `workflow`，不把日程顺序称为物理因果。
公共报告中的 `max_causal_depth` 是既有命名，可能被连续采样的 `scheduled` 边主导，不能把该数值直接当作气候物理因果深度。

样本包含采样时刻、温度异常、状态和序号；报告原样保留这个快照，也记录报告时的模型当前异常。
迟到、乱序报告不会改写旧样本；较旧序号不能覆盖较新的可用报告或驱动过期通报。
通报反映**最新可用样本**，不是保证发布时刻的物理状态仍然相同，也不是持续异常确认或气候归因结论。

文本是对事件、物理量、类型角色、时间和关系类别的确定性投影。
LLM 仅审核与矫正表达，不能修改强迫、温度轨迹、时间、父事件或 QA 真值。

## 5. 六项公共约束在本领域的落点

1. 共享前缀保留温度、累计能量、活动强迫、异常持续计时和最新样本；物理时钟不在分支起点重新随机化。
2. 时间轴为相对 Julian year，1 year=365.25 day；内部统一秒，不冒充逐个真实日历年份。
3. 默认 30 年观察窗与事件个数分开；支持约束范围内的随机观察窗与短窗零事件，行政截断单独报告。
4. 三类功能边无人工社区或全局连通要求，不添加无意义单元连线。
5. 完整观察窗与首末事件跨度分开，窗外报告/确认候选右删失。
6. 保留历史热惯性、强迫贡献、累计能量、连续异常开始点及样本序号，不局限于一阶/二阶类型转移。

默认 30 年、每年采样使多数事件是采样/上报，长度自然较集中，不应把它包装成丰富的物理事件分布。
可使用 12–30 年的观察窗混合测试长度；这改变观察范围，不改变物理规律或人为指定事件数量。
完整服务器指令见 [Climate 验收协议](../../docs/CLIMATE_TEST_PROTOCOL.md)。

## 6. 尚未覆盖

未实现降水、干旱、热浪、季节循环、ENSO、气溶胶寿命、碳循环、冰雪反馈、深海第二响应时间尺度、真实空间热输送与观测噪声。
不把负强迫直接命名为某次真实火山，不把正强迫直接命名为某个排放情景。
这只是有明确物理约束的气候响应事件流子域；通过程序检查不等于完成真实世界统计验证或证明 LLM 理解能力提高。
